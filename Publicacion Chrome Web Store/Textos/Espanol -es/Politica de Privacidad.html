Politica de privacidad

Volume Booster by Premium11

Esta Politica de Privacidad explica como Volume Booster by Premium11 trata informacion cuando las personas instalan, configuran y usan la extension de Chrome y sus superficies publicas de soporte asociadas.

URL publica requerida por Chrome Web Store

Volume Booster by Premium11 trata informacion vinculada a actividad de navegacion, ajustes de la extension, activacion premium y diagnosticos tecnicos, por lo que el producto debe respaldarse con una URL publica de politica de privacidad en el dashboard de Chrome Web Store. Este documento es el texto publico final pensado para esa funcion en https://www.premium11.com/privacidad.

Identidad y alcance

Esta Politica de Privacidad aplica a Volume Booster by Premium11, incluyendo el paquete de la extension, el popup, el runtime de fondo, el documento offscreen de audio, el runtime del booster automatico en paginas compatibles y el canal publico de soporte operado por Premium11. Cubre como se maneja la informacion cuando un usuario potencia audio, guarda preferencias, activa premium o contacta soporte.

Que hace la extension

Volume Booster by Premium11 esta diseñada para hacer que las pestañas silenciosas de Chrome suenen mas fuerte, mas claro y con mas control. Ofrece un booster manual para la pestaña actual, un carril automatico en paginas compatibles, comportamiento recordado por sitio y herramientas premium como protector de distorsion, perfiles de sonido y normalizacion de volumen.

Categorias de datos tratadas

La extension trata contexto de pestaña como URL de la pagina, dominio, titulo, referencia de favicon, identificador de pestaña y estado del runtime cuando esos datos se necesitan para etiquetar, controlar y restaurar sesiones de boosting. Tambien guarda ajustes locales como niveles de gain, comportamiento recordado por sitio, controles avanzados de audio, email de compra premium, datos de activacion offline y estado de la prueba premium de 30 dias dentro del almacenamiento controlado por el navegador.

Las releases publicas tambien envian diagnosticos tecnicos saneados a Sentry para monitoreo de errores. Volume Booster by Premium11 no recopila intencionalmente datos de tarjetas de pago, ubicacion precisa, datos de salud, contenido de mensajes ni audio capturado para analisis remoto.

Por que se necesita la informacion

El contexto de pestaña y pagina permite apuntar a la sesion correcta, determinar si el booster automatico puede adjuntarse, mostrar al usuario que se esta potenciando en ese momento y restaurar comportamiento recordado por sitio. Los datos premium locales permiten validar licencias vitalicias offline en el dispositivo y hacer cumplir con precision la prueba integrada de 30 dias a traves de los canales de almacenamiento del navegador.

Los diagnosticos saneados de Sentry se usan para investigar crashes, fallos de runtime, errores de attach y problemas de confiabilidad en releases publicas. No se usan para perfilar usuarios ni para publicidad.

Permisos y accesos del navegador

Volume Booster by Premium11 usa activeTab para actuar sobre la pestaña elegida por el usuario, tabs para leer metadata necesaria para el control de sesiones, scripting para inyectar logica automatica en paginas compatibles, storage para guardar preferencias locales y estado premium, offscreen para mantener vivo el motor de audio manual despues de iniciar la captura, tabCapture para procesar localmente el audio de la pestaña actual y alarms para refrescar el vencimiento de la prueba en el momento correcto.

La extension declara ademas <all_urls> para que el booster automatico opcional y el comportamiento recordado por sitio funcionen en sitios compatibles donde el usuario decida usar el producto.

Procesamiento local frente a datos transmitidos

El boosting de audio ocurre localmente en el dispositivo del usuario dentro de Chrome. Los niveles de gain, controles avanzados, preferencias recordadas por sitio, estado de prueba, email de compra premium y datos de activacion offline permanecen en el almacenamiento del navegador controlado por la extension.

La informacion sale del dispositivo en casos limitados. Las releases publicas envian diagnosticos tecnicos saneados a Sentry y la UI puede pedir un favicon a DuckDuckGo cuando la pagina no provee uno usable. Volume Booster by Premium11 no sube audio capturado para procesarlo de manera remota.

Terceros y proveedores

Sentry recibe eventos diagnosticos saneados de las releases publicas de Volume Booster by Premium11 para que Premium11 pueda investigar crashes e inestabilidad del runtime. La implementacion esta configurada para limpiar o redactar campos sensibles similares a URLs, titulos de pagina, URLs de favicon, objetos de request y payloads de usuario antes de transmitirlos.

DuckDuckGo puede recibir una solicitud basada en el dominio cuando Volume Booster by Premium11 usa su endpoint de favicons para mostrar un icono reconocible del sitio dentro de la UI de la extension. Premium11 no vende datos de usuarios a estos proveedores.

Retencion y borrado

Las preferencias locales, los datos de activacion premium y el estado de prueba permanecen en el almacenamiento del navegador hasta que el usuario cambie ajustes, limpie datos de la extension o la desinstale. El estado temporal del runtime se descarta cuando termina la sesion de boosting relacionada.

La retencion de diagnosticos saneados en Sentry depende de la configuracion de retencion del proyecto Sentry de Premium11 usado por las releases publicas. Esa retencion remota no es necesaria para la funcionalidad principal de boosting.

Controles del usuario

Los usuarios pueden activar o desactivar boosting, alternar entre carriles manual y automatico, ajustar el sonido, borrar comportamiento recordado por sitio, limpiar datos premium guardados y desinstalar la extension en cualquier momento. Chrome tambien puede exponer controles de acceso a sitios dentro de la configuracion de extensiones para quien quiera limitar el comportamiento global.

Seguridad

Volume Booster by Premium11 distribuye su runtime dentro de la extension empaquetada y no depende de codigo ejecutable remoto para su comportamiento principal. El procesamiento de audio sucede localmente y los diagnosticos de las releases publicas se limitan a reporte tecnico saneado por medio de Sentry.

Premium11 usa los permisos declarados solo para respaldar la experiencia de boosting descrita aqui. El producto no esta construido como monitor remoto de navegacion ni como herramienta general de recoleccion de datos.

Menores y datos sensibles

Volume Booster by Premium11 no esta dirigida a menores y no esta diseñada para recopilar intencionalmente categorias sensibles como datos de salud, biometria, detalles financieros o contenido de comunicaciones privadas. Su proposito es controlar audio web dentro de Chrome.

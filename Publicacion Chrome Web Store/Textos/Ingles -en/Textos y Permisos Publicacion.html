Justificacion de permisos

  • activeTab: lets Volume Booster by Premium11 act on the tab the user explicitly chooses to boost instead of touching unrelated tabs.
  • alarms: keeps the 30-day premium trial timing accurate and refreshes entitlement state when the trial expires.
  • offscreen: keeps the manual audio engine alive after capture starts so boosting can continue when the popup closes.
  • scripting: injects the automatic booster runtime on compatible pages when Volume Booster by Premium11 needs page-level logic to attach.
  • storage: saves local settings, remembered site behavior, premium activation data and trial state in browser storage.
  • tabCapture: captures the current tab audio for the manual booster lane so Volume Booster by Premium11 can raise and shape playback in real time.
  • tabs: reads the active tab identity and metadata needed to label sessions, target the correct tab and manage booster state cleanly.

Justificacion de host permissions

  • <all_urls>: allows the optional automatic booster to work across compatible sites and lets Volume Booster by Premium11 apply remembered site-specific behavior wherever the user chooses to use it.

Declaracion sobre codigo remoto

Volume Booster by Premium11 does not download or execute remotely hosted application logic for its core boosting experience. If public releases send sanitized diagnostics to Sentry, that service is used only for telemetry submission and not to deliver executable product code.

Declaracion de uso de datos

Volume Booster by Premium11 processes tab audio locally to deliver boosting, stores gain settings, remembered site behavior, premium purchase email, offline license activation data and trial state in browser storage, and does not sell user data.

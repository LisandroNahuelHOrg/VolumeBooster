Copia este bloque en la descripción larga y revisa el límite real del dashboard si sigue sin estar documentado.

Prism Volume Booster helps users raise the volume of any Chrome tab with more control, cleaner peaks and a stronger listening experience than a basic gain slider. The extension combines real-time DSP processing, manual volume shaping and optional auto-boost behavior so users can recover weak audio without constantly readjusting each site. The product is designed for people who move between video platforms, music services, calls, learning content and low-volume web players. Users can boost the current tab, store site-specific gain preferences, keep advanced audio settings locally and choose between manual control or automatic boosting modes depending on how they browse. Prism Volume Booster focuses on one job: improving tab audio in Chrome while staying transparent about permissions and data use. Audio processing runs locally, settings stay in browser storage, and any optional observability build is limited to error telemetry rather than remote code execution.

Resume por qué existen los permisos reales del producto.

activeTab lets the extension interact with the tab the user explicitly chooses to boost. tabCapture and offscreen are required to capture and process that tab audio in real time, even when the popup is closed. scripting is used to inject only the tab-level logic needed for the selected page experience. storage keeps local preferences such as gain levels, advanced DSP settings and site-specific rules. tabs is used to identify and manage the tab the user is actively boosting.

The extension declares the host permission <all_urls> because users can boost audio on all sites, save per-site gain preferences and apply automatic boost behavior across arbitrary domains. This all-sites access supports the user-selected tab experience and is not used for background scraping or unrelated data collection.

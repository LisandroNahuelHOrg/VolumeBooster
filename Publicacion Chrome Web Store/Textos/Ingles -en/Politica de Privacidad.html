Privacy Policy

Prism Volume Booster

This Privacy Policy explains how Prism Volume Booster handles information when people install, configure and use the extension in Chrome. It is written to be the final public version referenced by the Chrome Web Store listing and related support surfaces.

Chrome Web Store Privacy Policy URL Requirement

Required. Prism Volume Booster handles information connected to browsing activity and extension operation, including current tab context, page titles, domains, saved site preferences and limited technical diagnostics in releases that enable them. Under current Chrome Web Store privacy rules, products with this type of data handling should provide a publicly hosted privacy policy URL in the dashboard.

This document is written as the final text intended for that stable public URL. It explains what the extension does, what information it touches, what stays local on the device, what may be transmitted to service providers in limited cases, and what choices users have.

Identity And Scope

This Privacy Policy applies to Prism Volume Booster, including the Chrome extension package, the popup interface, the background runtime, the offscreen audio document used for manual boosting, and the public support channels linked to the product.

It covers how we process information when a user installs the extension, boosts audio in Chrome, saves preferences, uses automatic boosting behavior, or reaches out through a public support channel that is associated with the product.

What The Extension Does

Prism Volume Booster is designed to make quiet Chrome tabs louder, clearer and easier to control. It gives users a manual boosting lane based on tab audio capture, plus an automatic lane for compatible pages, together with saved preferences and advanced sound controls.

The product is focused on improving browser playback for videos, streams, lessons, calls and other web media without pretending to do unrelated jobs such as account management, payments or remote media hosting.

Data Categories Processed

We process the current tab URL, page title, domain, tab identifier, media state and favicon reference when those details are needed to identify, label and control the active booster session.

We store local settings such as saved gain values, advanced sound preferences, automatic booster mode and site-specific remembered behavior in the extension's browser storage area.

Some releases may also process sanitized technical diagnostics for reliability monitoring. Prism Volume Booster does not intentionally collect payment data, health data, biometric data, precise location data or the full content of personal communications.

Why The Data Is Needed

Tab and page context are used to identify the correct session, show the user which tab is being boosted, determine whether automatic boosting can attach to the current page, and remember site-specific preferences in a way that feels predictable and useful.

Local settings are used to restore the user's chosen sound profile, gain level and automatic behavior without forcing the user to start from scratch every time. Sanitized diagnostics, when enabled for a release, are used only to investigate crashes, runtime failures and product reliability issues.

Permissions And Browser Access Used

Prism Volume Booster uses activeTab to act on the tab the user chooses to control, tabs to read the tab metadata needed for session handling, scripting to inject the automatic booster runtime on supported pages, storage to save preferences, offscreen to keep the manual audio pipeline alive after capture begins, and tabCapture to capture the current tab audio for the manual booster path.

The extension also declares <all_urls> host access so the optional automatic booster can work on compatible sites across the web and apply remembered site-specific behavior wherever the user chooses to use the product. That access is tied to the booster experience and not to unrelated scraping or data brokerage.

Local Processing Vs Transmitted Data

Audio boosting happens locally on the user's device inside Chrome. Booster state, gain preferences and advanced sound settings are stored locally in browser storage and are used by the extension to preserve the user's chosen experience.

Information may leave the device in limited cases. The extension may request a favicon from DuckDuckGo's favicon endpoint when a page does not provide a usable icon, and some releases may send sanitized technical diagnostics to Sentry when observability is enabled. Prism Volume Booster does not upload captured tab audio for remote processing.

Third Parties And Service Providers

DuckDuckGo may receive a request for a favicon image when the extension uses its favicon service to display a recognizable icon for a tab or domain. That request is limited to the domain needed for the image lookup.

Some releases may enable Sentry for error monitoring and technical diagnostics. When Sentry is enabled, the extension sends sanitized telemetry intended to help us investigate crashes and runtime instability. Sensitive fields such as tab URLs, page titles, favicon URLs and direct request objects are reduced or redacted before transmission.

Retention And Deletion

Local preferences remain in the extension's storage area until the user changes them, clears extension data or uninstalls the extension. Temporary runtime state used to manage the current audio session is discarded when the relevant session ends.

If a release enables Sentry diagnostics, retention for transmitted diagnostic events is governed by the Sentry project configuration used for that release. We do not rely on remote retention for core boosting functionality.

User Controls

Users can enable or disable boosting, switch modes, adjust sound settings, remove remembered site preferences and stop using the extension at any time. Users can also remove the extension from Chrome, which removes the extension package and its local storage area from the browser.

Chrome may also expose host-access controls for the extension through the browser's extension settings. Users who no longer want site-wide automatic behavior can review those controls together with the extension's own in-product settings.

Security

Prism Volume Booster ships its application runtime inside the packaged extension and does not depend on remotely hosted executable code for its core product behavior. Audio processing is performed locally in the browser environment rather than by sending media to a remote boosting service.

When optional diagnostics are enabled, the transmitted payload is intentionally limited and sanitized. Access to tabs, storage and page injection is constrained by the permissions declared in the extension package and used to support the booster experience described in this policy.

Children And Sensitive Data

Prism Volume Booster is not directed to children and is not designed to intentionally collect or infer sensitive personal data categories. The extension is built to improve web audio playback, not to profile users or build sensitive behavioral dossiers.

Users should still use caution when playing confidential or sensitive content on shared devices, because browser audio tools operate in the context of the user's own browsing environment.

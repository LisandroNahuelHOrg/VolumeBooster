Privacy Policy

Volume Booster by Premium11

This Privacy Policy explains how Volume Booster by Premium11 handles information when people install, configure and use the Chrome extension and its connected public support surfaces.

Chrome Web Store Privacy Policy URL Requirement

Volume Booster by Premium11 handles information connected to browsing activity, extension settings, premium activation and technical diagnostics, so the product should be backed by a public privacy-policy URL in the Chrome Web Store dashboard. This document is the final public text intended for that role at https://www.premium11.com/privacidad.

Identity And Scope

This Privacy Policy applies to Volume Booster by Premium11, including the extension package, popup, background runtime, offscreen audio document, automatic booster runtime on compatible pages and the public support channel operated through Premium11. It covers how information is handled when a user boosts audio, stores preferences, activates premium or contacts support.

What The Extension Does

Volume Booster by Premium11 is designed to make quiet Chrome tabs louder, clearer and easier to control. It offers a manual booster for the current tab, an automatic lane for compatible pages, remembered site behavior and premium tools such as distortion protection, sound profiles and volume normalization.

Data Categories Processed

The extension processes tab context such as page URL, domain, title, favicon reference, tab identifier and runtime state when those details are needed to label, control and restore booster sessions. It also stores local settings such as gain values, saved site behavior, advanced audio controls, premium purchase email, offline license activation data and 30-day premium trial state in browser-controlled storage.

Public releases also send sanitized technical diagnostics to Sentry for error monitoring. Volume Booster by Premium11 does not intentionally collect payment card data, precise location data, health data, message contents or captured audio for remote analysis.

Why The Data Is Needed

Tab and page context let Volume Booster by Premium11 target the correct session, determine whether automatic boosting can attach, show the user what is currently being boosted and restore remembered site-specific behavior. Local premium data is needed to validate lifetime licenses offline on the device and to enforce the built-in 30-day trial accurately across browser storage channels.

Sanitized Sentry diagnostics are used to investigate crashes, runtime failures, attach errors and reliability issues in public releases. They are not used to profile users or to deliver advertising.

Permissions And Browser Access Used

Volume Booster by Premium11 uses activeTab to act on the tab the user chooses, tabs to read the metadata needed for session control, scripting to inject automatic booster logic on compatible pages, storage to keep local preferences and premium state, offscreen to keep the manual audio engine alive after capture starts, tabCapture to process current-tab audio locally, and alarms to refresh trial expiry at the correct time.

The extension declares <all_urls> so the optional automatic booster and remembered site behavior can work across compatible sites where the user chooses to use the product.

Local Processing Vs Transmitted Data

Audio boosting runs locally on the user's device inside Chrome. Gain settings, advanced controls, remembered site preferences, trial state, premium purchase email and offline license activation data remain in browser storage controlled by the extension environment.

Information leaves the device in limited cases. Public releases send sanitized technical diagnostics to Sentry, and the UI may request a site favicon from DuckDuckGo's favicon service when the browser page does not provide a usable icon. Volume Booster by Premium11 does not upload captured tab audio for remote processing.

Third Parties And Service Providers

Sentry receives sanitized diagnostic events from public releases of Volume Booster by Premium11 so Premium11 can investigate crashes and runtime instability. The implementation is configured to scrub or redact sensitive URL-like fields, page titles, favicon URLs, request objects and user payloads before transmission.

DuckDuckGo may receive a domain-based favicon lookup request when Volume Booster by Premium11 uses its favicon endpoint to display a recognizable site icon in the extension UI. Premium11 does not sell user data to these providers.

Retention And Deletion

Local preferences, premium activation data and trial state stay in browser storage until the user changes settings, clears extension data or removes the extension. Temporary runtime state is discarded when the related booster session ends.

Sentry retention for sanitized diagnostics depends on the retention settings configured for the Premium11 Sentry project used by public releases. That remote retention is not required for Volume Booster by Premium11's core boosting functionality.

User Controls

Users can enable or disable boosting, switch between manual and automatic lanes, adjust sound settings, remove remembered site behavior, clear stored premium activation data and uninstall the extension at any time. Chrome may also expose host-access controls in the browser's extension settings for users who want to limit site-wide behavior further.

Security

Volume Booster by Premium11 ships its runtime inside the packaged extension and does not depend on remotely hosted executable code for its core product behavior. Audio processing happens locally, and public-release diagnostics are intentionally limited to sanitized technical error reporting through Sentry.

Premium11 uses the extension's declared permissions only to support the booster experience described here. The product is not built as a remote browsing monitor or a general-purpose data collection tool.

Children And Sensitive Data

Volume Booster by Premium11 is not directed to children and is not designed to intentionally collect sensitive categories such as health data, biometric data, financial account details or the content of private communications. The extension's purpose is web-audio control inside Chrome.

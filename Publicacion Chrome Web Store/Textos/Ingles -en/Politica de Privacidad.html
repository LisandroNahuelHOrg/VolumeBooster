Privacy Policy

Prism Volume Booster

This Privacy Policy explains how Prism Volume Booster handles information when users install and use the extension in Chrome.

Chrome Web Store Privacy Policy URL Requirement

Required. Prism Volume Booster handles information related to browsing sessions, including page URLs, titles, domains, remembered site preferences and optional technical diagnostics that may be transmitted when a release enables them. Under current Chrome Web Store privacy rules, this product should reference a publicly hosted privacy policy URL in the dashboard. This final text is written to be published at that stable public URL.

Identity And Scope

This Privacy Policy applies to Prism Volume Booster, including the Chrome extension package, its popup and background runtime, the offscreen audio processing document used for manual boosting, and the support and privacy channels referenced by the product. It explains what information we process, why we process it, when information may leave the device, and what controls users have.

What The Extension Does

Prism Volume Booster increases and shapes audio playback from Chrome tabs. It offers a manual boosting lane based on tab capture and an automatic site-aware lane for compatible pages, together with live sound controls and local remembered preferences.

Data Categories Processed

We process the current tab URL, page title, domain, tab identifier, favicon reference, page media state and local booster settings that are needed to identify and operate each audio session. We store local settings such as remembered site gains, automatic boosting mode and advanced sound preferences in extension storage. If a release enables diagnostics, we may process sanitized technical error and performance telemetry. We do not intentionally collect raw tab audio for remote processing, payment data, health data or precise location data.

Why The Data Is Needed

We use tab and page context to determine which session the user is controlling, label active booster sessions in the interface, decide whether automatic boosting can attach, and remember site-specific preferences locally. We use local settings to restore the chosen booster mode and sound configuration. If diagnostics are enabled for a release, we use sanitized technical telemetry to investigate crashes, regressions and reliability issues.

Permissions And Browser Access Used

Prism Volume Booster uses `activeTab` to act on the tab the user is controlling, `tabs` to read tab metadata needed for session handling, `scripting` to inject the automatic booster runtime on compatible pages, `storage` to save local preferences, `offscreen` to keep the manual audio pipeline alive after capture begins, and `tabCapture` to capture the current tab audio for the manual booster. The extension requests `<all_urls>` host access so the automatic booster can run on compatible pages across sites when the user enables that mode.

Local Processing Vs Transmitted Data

Audio processing happens locally on the user's device inside Chrome. Booster state and remembered preferences are stored locally in the extension's storage area. Information may leave the device only in limited cases. If a release enables Sentry diagnostics, sanitized technical telemetry may be sent to Sentry. In addition, the extension may request a favicon from `icons.duckduckgo.com` when a page does not provide a usable icon. Prism Volume Booster does not upload tab audio for boosting.

Third Parties And Service Providers

DuckDuckGo may receive a request for a favicon image when the extension uses its favicon endpoint to display tab identity. Some releases may enable Sentry for error monitoring. When Sentry is enabled, the extension sends sanitized technical diagnostics to Sentry. Sensitive fields such as full tab URLs, titles and direct request metadata are reduced or redacted before transmission.

Retention And Deletion

Local settings remain in extension storage until the user changes them, clears the extension's data, or uninstalls the extension. Runtime session data used to manage audio playback is temporary and expires when the relevant session ends. If a release enables Sentry, retention for transmitted diagnostics is governed by the Sentry project configuration for that release.

User Controls

Users can enable or disable boosting, change the active mode, adjust sound settings, and stop using the extension at any time. Users can remove the extension from Chrome, which removes the extension package and its local storage area. Users can also control Chrome host access permissions through the browser's extension settings when Chrome exposes those controls for the installed extension.

Security

Prism Volume Booster ships its runtime in the packaged extension and does not download remote-hosted application code for execution. Access to tabs, storage and page injection is limited to the extension permissions described above. Optional diagnostics are sanitized before transmission when enabled.

Children And Sensitive Data

Prism Volume Booster is not directed to children. The extension is designed to control audio playback and is not intended to collect or infer sensitive personal data categories. Users should avoid using browser audio tools to process confidential material on shared devices.
